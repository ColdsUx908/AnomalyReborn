# Transoceanic 1.3 兼容性契约

本文约定 1.3 发布线的公共 API、网络载荷、生成器及数学边界。当前工作区仍是待发布源码；发布时以对应提交、DLL/XML 和验证资料包共同标识构建，不以版本号推断已完成真实宿主验证。

## 公共 API

- 1.3 相对 1.2 有源码、二进制及网络不兼容变更，所有消费方必须重新编译。具体迁移见 [迁移说明](Migration-1.3.md)。
- 发布之后，同一 1.3 维护线保留已发布的公共与受保护类型、成员签名、访问级别、默认参数及泛型约束。删除、缩窄访问或改变已有网络格式必须进入新的不兼容发布，并明确通知消费方；新增 API 仍需检查重载解析兼容性。
- internal/private 实现与生成文件分组、编号不属于兼容承诺。生成器辅助反射字段、委托的编码后缀也不作为手写调用接口；消费方通过生成的包装方法使用能力。非重载 TypeDetour 的既有 Orig_Name、Detour_Name 入口保留。
- Behavior 是按类型共享的 ModType 内容；实体数据存于实体、Global 实例或 ModPlayer。禁止缓存绑定后单例或在锁定回调中将同一实例改绑到另一实体。实际调度、克隆与清理约定见 [加载生命周期](../Core/Loading/README.md)。
- 独立验证资料包中 ReleaseReadiness/PublicApi-1.3.txt 记录当前候选的公共/受保护 API。普通验证只比较，显式 --update-api 才更新；更新前必须审查差异及迁移说明。候选发布后的基线不得为了消除失败而自动重写。

## 网络

Transoceanic 保持 side = NoSync。不需要 Ocean 同步的单端数学/视觉消费方不启用同步。需要同步的消费方必须为 Both、正式强依赖框架，并在各端原生 Load 中无条件调用 EnableSync(Mod)。各端框架和消费方必须使用相同构建；没有远端握手或协议协商，版本号相同不保证未发布构建可混用。完整约束见 [网络约定](../Game/Networking/README.md)。

- EnableSync 是新代码唯一推荐启用入口。SyncEnabled setter 在整个 1.3 线继续兼容旧代码，不增加 Obsolete 编译警告；未登记消费方的启用会在设置完成时警告。首次启用必须在内容设置完成前，启用后本加载周期不能关闭。后续不兼容版本才考虑移除 setter，届时另行公告。
- NPC OceanAI32 为 12 个数据槽加 1 个尾部变化标记槽；弹幕为 7 个数据槽加 1 个标记槽。NPC Timer1..8 位于 4..11，弹幕 Timer1..5 位于 2..6。其余槽位不在本轮重新分配，不能混入已删除的 OceanAI64 段。
- SyncEnabled=false 时框架 ExtraAI 写入/读取零字节；true 时 NPC 与弹幕各写一段 AI32 完整稀疏快照。不使用 BitWriter 位字段，不添加容量头、协议头或 AI64 段。本轮不改变现有载荷。
- 快照使用 BinaryWriter/BinaryReader 的小端整数：Int32 条目数，随后按索引严格升序重复 Int32 索引 + Int32 原始位型。只有原始整数位型为零的槽省略；负零和 NaN 位型不得通过浮点转换丢失。尾部标记不发送也不由写入方清除。
- 通用 AI64 快照采用相同布局，但值为 Int64；它不是 Ocean ExtraAI 的组成部分。增量工具是另一种独立协议，必须成对使用，不能与快照读写混搭。
- 完整快照接收成功后替换整个数组：省略的数据与尾部标记清零。数量、索引、顺序错误或截断失败不修改目标数组；流位置不会回滚。写入失败可能留下部分字节，调用方不能把它作为完整包发送。
- ReleaseReadiness 使用固定十六进制样例分别验证编码和解码，防止读写双方同时变化掩盖协议漂移。往返检查仍单独保留。框架不自动同步任意字段、物品 Behavior 或 PlayerBehavior，也不替消费方决定生成权限。

## 源生成器

- Publicize 与 TypeDetourClass 标注的包装类型及其外层类型必须为 partial class；TypeDetour 模板至少有一个类型参数。不满足时报告 TOGEN001 错误。
- Publicizer 辅助名称在旧短名冲突时使用完整参数类型与引用修饰的可逆编码，区分命名空间、泛型实参、数组秩与 ref/out/in。TypeDetour 为重载生成带完整签名后缀的入口，非重载保留原名；运行时仍由委托签名定位目标。
- 泛型方法、引用返回、不可访问的签名类型及 ref readonly 参数当前不自动生成，报告 TOGEN002 警告；使用显式包装或手动钩子。Publicizer 非公开索引器不生成并报告 TOGEN002。整类宿主包装中的已知不可访问方法可以在对应包装文件内显式抑制 TOGEN002，不能全项目屏蔽消费方诊断。
- 源码开发中生成器作为 Analyzer 引用，不作为游戏运行时依赖。实际 DLL-only 消费方测试仅存在 Tests 中，不编入框架。

## 几何与数学边界

- 调用几何算法时坐标、尺寸应为有限值，宽高与半径非负；直接写入结构体公开字段的调用方负责维持约束。Circle 构造拒绝非有限或负半径；Annulus 构造拒绝非有限半径、负内半径及内半径大于外半径。Sector 构造校验半径、角度及半张角。
- RotatedRectangle.FromLineSegment 的 width 是完整宽度，端点是两条短边的中点。零位移形成零长度退化矩形，零宽度形成线段，不隐式扩展成圆或方形。
- 旋转矩形碰撞的边界接触计为相交，其 AABB 预筛必须保留接触与退化输入；普通 FloatRectangle.Collides 仍使用严格面积重叠，两个接口不承诺相同边界语义。
- MathInterval 接受无穷端点；正负无穷端点只能开放，构造时对应 inclusive 参数规范化为 false。NaN 端点、倒置端点、开放的同点区间以及无穷同点区间均为空；Contains 对无穷值本身和 NaN 返回 false。
- NormalizeWithPeriod 要求有限正周期，否则抛出 ArgumentOutOfRangeException；非有限输入值产生 NaN。ShortestDifference 的半周期平局选正方向，范围为 (-period/2, period/2]。
- 缓动默认将进度限制到 [0,1]，NaN 按浮点运算传播。BezierCurve 复制控制点，进度限制到 [0,1]，区间采样数量必须大于零。

## 宿主内部依赖

NPCScalingCompatibility 在原生内容 Load 中调用 TONPCUtils.ValidateHostCompatibility，提前检查 NPC 私有缩放方法的完整签名、唯一的静态四参数缩放钩子及动态委托生成。失败中止加载，异常包含宿主程序集版本、目标方法与内部原因，不静默使用错误倍率。

该检查只验证当前所依赖的结构，不证明任意 tML 版本的血量算法语义一致。升级宿主后必须重审专家倍率计算流程；离线测试同时检查实际宿主结构及被破坏的 IL，真实钩子链与战斗行为仍需另行验证。
