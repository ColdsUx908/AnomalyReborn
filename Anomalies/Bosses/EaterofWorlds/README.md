# 世界吞噬怪

## 战斗与数值

Ultra 与普通 Anomaly 使用同一套 AI，旧 AI 已移除。`Phase1` 在共享生命不高于 50% 后，于下一次攻击切换进入 `Phase1_2`；不中断正在预警的攻击。血条显示对应亚阶段标记。

循环：游猎 → 两次犁地冲锋 → 传送分裂 → 三首轮猎 → 交错封路 → 传送重组 → 游猎。奇数轮交换轮猎和封路顺序，同时镜像攻击方向。50% 亚阶段将轮猎次数从 4 提高到 5、基础冲锋速度从 21 提高到 23、游猎从 270 帧缩短到 210 帧。轮猎预警 36 帧，冲锋第 12 帧沿锁定方向补三发扇形火球。攻击结束后保留惯性进入下次就位。

分裂和重组先向远离玩家的 1700 像素集结点撤离；至少 45 帧且所有现有头部离玩家 1100 像素后，才开启入口与出口裂隙。撤离超过 450 帧仍不满足条件时跳过本次转换。出口在玩家移动方向前方 600 像素，预警开始后位置固定，方向继续追踪玩家。入口采用神明吞噬者的青紫旋涡，虫体依照链内顺序隐去；出口保留其 180 帧裂隙蓄力、三次玻璃破裂、十字星、收缩光环、爆裂粒子、裂纹和流动的扭曲填充效果。声音、纹理和着色器均使用本地副本，不调用灾厄 AI、粒子处理器或绘制系统。来源与版权见 [Portal/README.md](Portal/README.md)。

蓄力结束的同一服务器边界执行分裂/重组，所有新头部从同一裂隙以 34 速度冲出；分裂保留约 ±50° 的三路扇形。转换复用原体节并保留共享生命，出场前清理轨迹，身体逐节从出口展开。所有头部离出口至少 1200 像素、且最后的尾部已展开后进入下一动作。隐藏/尚未出场的体节不造成接触伤害并获得 95% 减伤。出生仍使用原先紧凑盘绕及灰紫烟雾，分合不再使用烟雾遮罩。

其他攻击维持原有运动与预警：单头、轮猎和封路预警期间正常追逐，头部朝向跟随速度；方向在实际冲锋边界锁定，封路第二头延后 24 帧冲锋。轮猎仅当前猎手冲锋时造成接触伤害。预警使用世界坐标绘制，主头离屏时依然可见。封路场地不适用或就位超时会安全跳过。

基础共享生命为 9000 / 灾厄启用时 12000，是当前克苏鲁之眼基础生命的两倍；遵循同一多人和灾厄生命增幅接口。正常 Anomaly 火球预设伤害 108（眼球为 96），头/体/尾接触伤害为 108/66/54，防御 8。火球附带 90 帧诅咒狱火。已有 Ultra 90 体节及 180 火球伤害保留，普通 Anomaly 为 60 体节。没有 Ultra 专属攻击或阶段。

传送以外的体节保持正常透明度。着色器关闭时保留星芒、粒子和简化扭曲轮廓；专用服务器不加载视觉资产。云雾与风按视口比例修正，保持 16:9 基准。

## 状态与分合

- `ai[0]` 打包主头、局部头、局部前驱、局部后继索引；0 为空，其他为 NPC 索引 + 1。
- `ai[1]` 是不可变的全局体节序号。主头身份不依赖分裂时会改变的局部前驱。
- `ai[2]` 打包 Phase 和 Behavior，`ai[3]` 是行为内部步骤。具体步骤见 Phase1AI 内注释。
- 额外 32 位槽：0 的 bit0 表示分裂、bit1 表示体节轨迹已初始化；1 为盘绕朝向；2 保留；3/4 为攻击次数/循环次数。
- 额外 64 位槽：0 为出生盘绕中心/传送出口，1 为攻击中心/撤离集结点，2 为瞄准点，3 为各头锁定方向。Timer1 为当前步骤时钟。
- 主头统一调度头部运动和攻击，服务器负责步骤推进、重组与弹幕生成。客户端从同步的主头关系恢复头部列表，不依赖服务器本地 AllSegments。
- `EaterofWorldsTopology` 生成局部链，转换前验证体节数量、所属关系和顺序。转换复用 NPC，保留共享生命，同时更新 type 和 netID、清理轨迹缓存。传送步骤为 0 撤离、1 入口隐去与出口蓄力、3 出场；Timer1 由服务器在边界归零。死亡先清理子体节，让原版掉落和击杀记录只结算一次；退场直接清理，不触发奖励。

## 验证

自动验证命令：

- `dotnet build Anomalies/Anomalies.csproj --no-restore -m:1 -p:BuildMod=false`
- `dotnet run --project Tests/EaterofWorlds.Topology/EaterofWorlds.Topology.csproj`
- `dotnet run --project Tests/EaterofWorlds.Portals/EaterofWorlds.Portals.csproj`
- `pwsh -NoProfile -File Tests/BossIsolation/Verify.ps1`
- `python Tests/BossIsolation/verify_dependencies.py`

拓扑测试覆盖 60/90 节反复分合、局部链双向一致性、不重复/不遗漏体节、非法分裂请求。传送测试调用实际编译出的裂隙类型，覆盖蓄力快照、中途加入、爆裂淡出、重复快照不累加裂纹缩放，以及绘制缓存不进入额外同步载荷。

仍需游戏内验证：普通/Ultra 完整两轮循环、低机动装备躲避空间、50% 阈值、地表/地下/平台/狭窄场地、两次同时召唤、死亡/退场奖励、客户端中途加入、分合时延迟，以及有/无灾厄时的实际伤害和资源加载。静态编译与拓扑测试不能代替这些检查。
