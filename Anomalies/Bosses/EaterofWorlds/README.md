# 世界吞噬怪

## 战斗与数值

Ultra 与普通 Anomaly 使用同一套 AI，旧 AI 已移除。`Phase1` 在共享生命不高于 50% 后，于下一次攻击切换进入 `Phase1_2`；不中断正在预警的攻击。血条显示对应亚阶段标记。

循环：游猎 → 两次犁地冲锋 → 盘绕分裂 → 三首轮猎 → 交错封路 → 归巢合击 → 游猎。奇数轮交换轮猎和封路顺序，同时镜像攻击方向。亚阶段将轮猎次数从 4 提高到 5、基础冲锋速度从 21 提高到 23、游猎从 270 帧缩短到 210 帧。分裂和合并的出场冲锋统一以 34 速度从中心出发，所有头部离开中心至少 1200 像素后才进入下一动作；轮猎额外加速 4、预警 36 帧，冲锋第 12 帧沿锁定方向补三发扇形火球。攻击结束后保留惯性直接进入下次就位，不再插入恢复或休息步骤。

预警方向实时追踪目标，只在各头实际起冲边界锁定；封路双头分别瞄准玩家上下两侧，第二头延后 24 帧锁定并发起冲锋。头部以 10 帧平滑加速度起冲、平滑转向；单头、轮猎和封路的冲刺预警均维持正常追逐移动，分合出场预警则保持在遮罩内绕圈，头部朝向只跟随速度，不随预警线摆动；未冲刺的分头持续追逐玩家，换头保留原有惯性。取消封路前强制拉直身体，盘绕吸入速度受限。出生和分合使用随环境光变色的灰紫色烟雾遮盖盘绕：两层不规则噪声软边纹理缓慢交错，烟尘混合少量腐化碎屑，不再绘制同心圆、花瓣或盘绕圆环，SmoothStep 控制淡入淡出，粒子密度、尺寸和透明度跟随遮罩强度。遮罩在 NPC 绘制后覆盖，不改变体节透明度；遮罩中心 180 像素内体节通过 AnomalyNPC.DR 获得 95% 减伤且不造成接触伤害，离开后恢复 DR 为 0。诅咒火球采用原版敌对诅咒焰的 16×16 碰撞框、1.3 倍绘制缩放、GetAlpha 颜色、旋转和绿光；飞行时在下一帧位置生成 3×scale 的无重力诅咒火尘，死亡时生成原版两组共 40 个尘土，播放原版生成和消失音效。

分合时头部以最高 38 速度进入遮罩，随后以最高 32 速度持续绕圈；身体只跟随前驱，紧弯时沿前驱的 16 帧轨迹按弧长跟随，避免抄近路停在圆心。所有体节进入中心 170 像素内后才开始重组预警，分合只改链接，不重排身体坐标；各头起冲时在遮罩覆盖下归到中心并立即获得冲刺速度；若过久无法收拢，则跳过本次转换。遮罩内紫色方向预警从盘绕中心发出，分裂恢复中心线两侧各 SplitSpread（约 50°）的三路扇形，各路预警继续追踪目标并在各自起冲时锁定。

出生时所有体节在半径 140 的紧凑圆周上盘绕，立即开始游猎攻击，由头部持续绕行逐渐拉出，不再设置无攻击的出场步骤。跟随只拉近距离过远的体节，不强行撑开已压紧的链，因此分合后的盘绕也会随头部移动展开。方向预警使用公共 DrawLayeredWarning 叠层光束，长度上限为 520（游猎 280）像素，16 帧平滑伸展、10 帧淡入、末尾 8 帧淡出；圆环显式采样 1×1 像素并随预警淡入淡出。光束采用与遮罩协调的灰紫色，宽度最高 60 像素、亮芯 5 像素，起点前 120 像素按 SmoothStep 渐入；离开遮罩时发射起点从盘绕中心平滑过渡至头部。

基础共享生命为 9000 / 灾厄启用时 12000，是当前克苏鲁之眼基础生命的两倍；遵循同一多人和灾厄生命增幅接口。正常 Anomaly 火球预设伤害 108（眼球为 96），头/体/尾接触伤害为 108/66/54，防御 8。火球附带 90 帧诅咒狱火。已有 Ultra 90 体节及 180 火球伤害保留，普通 Anomaly 为 60 体节。没有 Ultra 专属攻击或阶段。

所有体节保持正常透明度，接触伤害关闭时也不再额外变淡。阵形整理、分合重排及重排后的预警期间不会通过位置修正伤害玩家；轮猎仅当前猎手冲锋时有接触伤害。预警使用世界坐标绘制，主头离屏时依然可见。封路场地不适用或就位超时会安全跳过，不强制瞬移玩家或无限等待。

## 状态与分合

- `ai[0]` 打包主头、局部头、局部前驱、局部后继索引；0 为空，其他为 NPC 索引 + 1。
- `ai[1]` 是不可变的全局体节序号。主头身份不依赖分裂时会改变的局部前驱。
- `ai[2]` 打包 Phase 和 Behavior，`ai[3]` 是行为内部步骤。具体步骤见 Phase1AI 内注释。
- 额外 32 位槽：0 的 bit0 表示分裂、bit1 表示体节轨迹已初始化；1 为盘绕朝向；2 保留；3/4 为攻击次数/循环次数。
- 额外 64 位槽：0 为盘绕中心，1 为攻击中心，2 为瞄准点，3 为各头锁定方向。Timer1 为当前步骤时钟。
- 主头统一调度头部运动和攻击，服务器负责步骤推进、重组与弹幕生成。客户端从同步的主头关系恢复头部列表，不依赖服务器本地 AllSegments。
- `EaterofWorldsTopology` 生成局部链，转换前验证体节数量、所属关系和顺序。转换复用 NPC，保留共享生命，同时更新 type 和 netID、清理轨迹缓存。死亡先清理子体节，让原版掉落和击杀记录只结算一次；退场直接清理，不触发奖励。

## 验证

自动验证命令：

- `dotnet build Anomalies/Anomalies.csproj --no-restore -m:1 -p:BuildMod=false`
- `dotnet run --project Tests/EaterofWorlds.Topology/EaterofWorlds.Topology.csproj`
- `pwsh -NoProfile -File Tests/BossIsolation/Verify.ps1`
- `python Tests/BossIsolation/verify_dependencies.py`

拓扑测试覆盖 60/90 节反复分合、局部链双向一致性、不重复/不遗漏体节、非法分裂请求。

仍需游戏内验证：普通/Ultra 完整两轮循环、低机动装备躲避空间、50% 阈值、地表/地下/平台/狭窄场地、两次同时召唤、死亡/退场奖励、客户端中途加入、分合时延迟，以及有/无灾厄时的实际伤害和资源加载。静态编译与拓扑测试不能代替这些检查。
