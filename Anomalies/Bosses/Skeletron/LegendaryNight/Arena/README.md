# 竞技场边缘效果与 Wave2

机制6开始后，最外侧亮线周围在60帧内淡入金色流动雾幕，随后跟随竞技场半径收缩并保持。新增雾幕严格限制在圆周外侧，外侧延伸约300世界像素，使用更鲜艳的金色；圆内雾幕与边缘辉光均为零。原有场外迷雾合成后再绘制新增雾幕。原亮线、伤害范围及红色收缩预警保持原逻辑；红色预警绘制在新增雾幕之上。关闭着色器或资源未加载时跳过新增效果。

## 资源来源

`Assets/Textures/Noise/Wave2.png` 为本项目独立数学程序生成的512×512周期RGB灰度噪声，固定种子20261103；生成过程不读取任何参考图片。算法使用周期Perlin坐标扭曲、整数周期明暗带、低频fBm与周期模糊。未复制Fargo的视觉资产、图像数据或着色器代码。仅只读比较其WavyNoise的液态褶皱特征和边缘效果原理。

对比现有18张噪声后新增Wave2：Wave偏大块二值斑，Perlin2偏颗粒云，Melt2偏定向条纹，胞元及脉络噪声的结构也与目标差异明显。Wave2使用三层错向流动采样，获得同类柔滑褶皱效果；不声称逐像素或游戏内完全等价。
