# 传说之夜群星物质光球

机制6的小光球由LegendLightOrb提供，半径16世界像素。在1:59:55（第7195音乐帧）广播“拦截向它飘去的星神之力！”，并生成第一轮小球；之后每95帧一轮，共4轮、12球。第1、3轮两金一铂，第2、4轮一金两铂，随机打乱颜色后每个120°扇区各一颗，从竞技场外圆周出生；方位从正上方分界开始，无激光式最小夹角留边。每颗球由服务器独立选择出生至完全吸入的总时长：第一轮900至990帧，第二轮990至1080帧，第三轮1080至1170帧，第四轮1170至1260帧；最后30帧用于二次方加速吸入。出生30帧淡入，先漂至距球心1.5倍大球半径（当前360像素），即开始加速并径向拉长、切向压缩至球心归零。保留Perlin2流动球面与亮边，无内部星空和独立星核；局部等比例UV无需屏幕比例修正。2:41只保留安全清场，不再持续生成小球。

小球ai[0]为颜色（0金、1铂），ai[1]为出生音乐帧，ai[2]为出生角。ExtraAI按序写owner(int)、identity(int)、出生半径(float)、结算状态(byte)、总行程帧数(int)、实际碰撞玩家索引(short，未碰撞为-1)，共19字节（不含父载荷）。客户端据同步音乐时钟与独立行程恢复运动、淡入和吸入变形；主人失效或清场由服务器取消，取消不触发奖励或吸收。服务器在AI内直接检测半径16×scale的圆形与存活非幽灵玩家矩形的重叠，不受原版伤害碰撞和免疫帧限制。一颗球仅结算给首个接触玩家。拦截生成40颗LegendaryNightAbsorptionParticle，保留金/铂与白色5%至25%插值及加法亮度，不另叠白核。初速2至6，先弯曲散射6至10帧，再用10至14帧匀速降至零，完全停顿3帧后立即平滑转向并加速追踪实际碰撞玩家，目标速度从4逐步提高至24。每颗光点具有12点渐细尾迹，抵达玩家时缩小消失；目标死亡、离线或成为幽灵时直接清理，最长寿命240帧。只参考FargoSouls MutantHeal的散开、降速与惯性回流思路，自行实现粒子运动及尾迹，不生成治疗弹幕，不增加血量、不再次结算属性增益。碰撞玩家索引随小球结算同步，所有客户端追踪同一玩家，随机散射及尾迹缓存只保留在本地粒子中。

移动中的小球每帧从球体后沿（半径外再留4像素）向后喷出金/铂色GenericSparkle星芒，速度1.5至3.5，散角±0.22弧度，尺寸0.3至0.45倍、寿命24至36帧；随出生透明度与吸入尺寸减弱，快速吸入时按8世界像素补采样、单帧最多6颗。尾迹由大球实例独立ParticleSet持有和更新（上限1024），不占全局粒子容量，并按球面→尾迹→小球→星核顺序单独加法绘制，避免全局粒子被后绘制的竞技场雾幕或大球球面遮住。轨迹由同步时间方程重建，不使用网络收包跳变距离；仅客户端生成，不新增同步字段。小球结算后已有尾迹继续淡出，大球退场时清理集合。

每位玩家初始要求金球，成功后改为铂球，只有撞对才切换。金球使自己的伤害增益层数+1，每层使最终伤害倍率增加5个百分点，最终伤害统一乘1+0.05×层数；铂球使自己的生命再生增益层数+1，每层给原版lifeRegen加1。撞错则两种增益各减一层，允许负值（伤害-1层为×0.95，生命再生-1层为-1），不切换所需颜色，并立即生成一轮8束蓝激光。只有四轮全部生成且所属光球场上不再存在自己所需颜色时，才将另一颜色作为有效拦截免罚。每名玩家的两种层数和下次颜色由大球按槽位保存，和已生成波次一起完整同步；离线清零、死亡保留本场状态、光球退场后失效。AnomalyPlayer仅缓存每帧汇总的两种增益，不单独同步。星神祝福的中英文说明已更新。

大球与小球不再自行PreDraw，由二阶段竞技场通过 `LegendaryNightOverlay` 统一绘制，固定顺序为球面及内景 → 小球 → 星核。`LegendEnergySphere.fx` 的 `Pass0` 绘制球面，`Core` 绘制独立加法星核；局部等比例UV无需屏幕长宽比修正。吸入完成时星核瞬间放大65%、增强辉光，24帧内衰减回常态；无着色器时同样提供星核闪光回退。闪光仅为客户端视觉，不进入网络快照。每颗小球抵达球心时，仅服务器/单人端从大球中心生成40颗FallingStar，方向独立随机、速度大小4至6，使用既有TrailType=1蓝白光尾、0.2缩放、240帧寿命且不加速；同时触发一次大球实例事件 `LightOrbAbsorbed`，参数为该小球。拦截与吸收分别结算且互斥，取消或退场不会生成星星或触发事件。服务器先发送小球最终ExtraAI再发送删除包，客户端按结算状态播放拦截粒子或星核闪光，不再按OnKill时的年龄猜测原因。

蓄力时星芒从球面外侧四面八方生成，每帧10颗，在12至20帧内沿直线快速汇入球心。球内使用24个独立星光能量槽位，每个槽位每0.8秒从随机角度生成一条暖金短线，沿径向吸入中心星核。能量线头仅保留径向光波，移除角向展开的横翼。中间暗部参考EventideDeathSweep的星云、亮星与闪烁分层，以局部平面坐标生成疏密两层独立闪耀的星野，避免极坐标拉伸，不依赖其专属贴图。星核具有持续闪耀的白金核心、脉动光晕和八向星芒；降低周围球面的过曝以保留能量与星核的亮度对比。关闭着色器时保留原有星芒与光晕回退。

第12次星爆开始后，双手停止攻击玩家，从当前位置平滑过渡到托球姿势，并在光球开始蓄力的前一帧完成准备。进入机制6后至竞技场收缩开始前，以金币审判同款半透明红色遮罩预警半径640至780像素的收缩扫掠圆环。机制6法阵目标半径为640像素，内圈吸收和外圈半径过渡窗口均为30帧。机制6开始前的60帧，本体平滑下移；蓄力期间随光球半径增长继续调整高度，使光球始终处于法阵中心。头部中心与球面间距为64像素，默认头部高度下头顶保留约13像素空隙。当前仅生成第一颗光球，沿用原来的蓄力时长与三次方增长，完成后持续保持满蓄力和托球姿势，不投掷、不爆炸，也不生成后续光球。光球逐帧续期，主人退场或失效时清除并停止循环音效。原机制7的星网、手部公转、投掷回收及法阵退场流程已移除。

三次方蓄力增长和分层光晕参考 FargowiltasCrossmod 的 AresBodyEternity.DoBehavior_LargeTeslaOrbBlast_ManageSphere 与 LargeTeslaSphere。着色器保留 LargeTeslaSphereShader 的光球边缘构思，内部改为本项目的流动星辰，不再使用电噪声；参考 MEAC 羲和 Sun.fx 的径向亮度和角向光芒分层思路，自行实现金白色光带，没有复制其代码或资源。

Electric.png 位于 Assets/Textures/Noise，保留为通用资源，本光球不使用它。Perlin2.png 已替换为本项目周期 Perlin fBm 生成图，通过 AnomalyTextures.Noise 访问；LegendEnergySphere.fx 的三处噪声采样统一补偿均值与对比度，复现参数及迁移记录位于 Tools/NoiseGenerator/Perlin2/Parameters.json 和 Tools/NoiseGenerator/Perlin2/Migration.md。TeslaSphereLoop.ogg 保留在当前目录。导入资源及改编代码的 MIT 许可位于 Licenses/FargowiltasCrossmod-MIT.txt。

着色器使用局部方形精灵 UV，不需要屏幕长宽比修正。

Noise目录现已全部迁移为程序生成图，包括Electric；原导入对应关系仅保留为历史来源说明，原图及许可副本位于Backup/NoiseMigration。光球本身仍使用已迁移的Perlin2及其既有补偿。

机制6激光：1:58:20（第7100音乐帧）生成第一轮金色激光（每轮三束），1:59:55首次出伤；此后每190帧一轮，严格生成8轮，最后一轮2:20:30生成、2:22:05出伤。通过大球的SpawnLasers(count)指定数量n，从正上方分界线开始把场地均分为n个扇区，每道激光的最终方向占一个扇区；两端各留45°/n，保证最终任意两束夹角至少90°/n（n=1无需留边）。本轮所有方向选完后共用一个0至2π随机整体偏移，覆盖原扇区留边方向，且保留相对夹角；偏移直接合入同步的锁定方向，不增加网络字段。每束先用15帧显现，再用50帧按独立随机的有符号角度平滑旋转（-180°至180°），随后固定方向保持30帧；出现满95帧才开始20帧伤害窗口。激光全宽32像素、长度1800像素，命中施加15秒星力压制。最终方向、旋转角及生成由服务器决定；旋转角和蓝色惩罚标记通过一对ExtraAI按float、bool同步，客户端按同步的音乐起始帧预测；主人退场、失效或机制结束时清除。

预警及光束颜色公式由本机Radiance的RadiantBeam/RadiantBeamMarker XNB反汇编重建，绘制参数和20帧衰减参考Radiance.Projectiles.RadiantBeam。保留线型预警、集中辉光、波动光束；移除COLOR1输出、DistortionBatch、屏幕闪光和画面扭曲集成。两个效果仅依赖局部精灵UV和世界像素尺寸，无需新噪声或贴图，也不需要屏幕比例修正。关闭着色器时回退为同方向的金色线束。

解包工具及反汇编保存在Tools/XnbEffectUnpacker，DLL检查工具保存在Tools/RadianceInspect；交付时与Tests/LegendaryNight.Lasers一起纳入独立验证资料包，沿用Tools和Tests的忽略规则。

激光触发音效暂用Radiance的RadiantBeam.PlaySounds及RadiantBeamShot行为：叠加原版AbigailUpgrade（音量1、音高0.8）、Item122（0.8、0.4）、Item163（0.5、0.3），每层音高额外随机±0.2。每帧音量乘0.97、音高向-0.8衰减，低于0.02时结束；保留原版音效自身变体。每轮仅播放离本机玩家最近的光束，声源为光束上离玩家最近的点，沿用Radiance的2500像素平方根距离衰减和初始声像。尾音由SoundEngine回调管理，可自然延续至弹幕消失后；专用服务器不播放。此效果无需复制Radiance的音频文件，三层均来自Terraria原版声音。

激光及预警绘制使用AnomalyEffects容器的MiscShaderData，通过Transoceanic的SetCustomParameter设置参数并调用Apply应用已注册的Pass0，不直接操作原始Effect。激光动画时间参数使用uGlobalTime，避免被MiscShaderData.Apply自动写入标准uTime而改变原有动画时钟。

激光配色：默认底色由浅暖白改为RGB(255,209,15)，对应光球着色器gold的(1,0.82,0.06)。保持原亮度/透明度包络、精灵范围及32像素碰撞宽度，在原范围内缩窄发白核心，扩大金色可见外沿；关闭着色器时同样绘制金色外层与较窄暖白核心。

每束LegendEnergyLaser拥有独立的BeamColor自动属性，预警、激光及无着色器回退统一读取该颜色。可通过p.GetModProjectile<LegendEnergyLaser>().BeamColor = new Color(r,g,b)调整，alpha控制整体透明度。它是纯绘制数据，不写入网络快照；后续根据同步攻击类型设计不同颜色时，应在各端使用相同配置赋值。

配色二次调整：为避免激光出现金色实线描边，核心过渡范围由3轻微回退到4，外沿由硬亮度封顶改为连续柔和压缩；总包络及碰撞宽度保持不变。默认BeamColor改为Vector3.Lerp(LegendEnergySphere.GoldColor, LegendEnergySphere.StarlightColor, 0.4f)，不再单独维护一组金色值。光球的GoldColor=(1,0.82,0.06)、StarlightColor=(1,0.98,0.8)通过MiscShaderData传入着色器，保持光球原色不变；激光由这两个色混合得到较柔和的暖金色。无着色器回退的核心占比由35%调整至45%。


惩罚激光以NASA的Sirius A/B蓝白恒星示意图为配色参考，将原Radiance淡蓝改为RGB(125,155,255)的偏蓝外沿，保留着色器现有冷白核心过渡；这是游戏视觉调整而非真实恒星颜色标定，沿用同一光束及预警着色器，不依赖Radiance加载。与金激光相同，15帧淡入、50帧旋转、30帧锁定，满95帧后20帧出伤；按8个扇区生成，保留对应最小夹角。蓝激光通过AI单独检测本机玩家的旋转矩形碰撞并调用现有伤害入口，临时绕过immune、immuneTime和hurtCooldowns并恢复已有免疫状态，同一束对每个玩家在本次伤害窗口内最多结算一次；普通黄激光继续走原碰撞路径。

配色参考：[NASA：Sirius A与Sirius B示意图](https://science.nasa.gov/asset/hubble/an-artists-impression-of-sirius-a-and-sirius-b/)。只参考颜色，不导入图片、纹理或新的着色器。
